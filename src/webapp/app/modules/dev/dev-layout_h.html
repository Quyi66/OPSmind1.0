左右布局示例

基本示例代码:

                <div class="opx-layout-hflex">
                    <div>
                        左侧
                    </div>
                    <div class="opx-flex-fill">
                        右侧
                    </div>
                </div>

最外层opx-layout-hflex的高度为父容器的100%。

页面可以划分多列,每一个div元素代表一列,列宽默认自适应其内容。通常你需要给其中一列添加opx-flex-fill类来让其占满剩余宽度。其它列设置固定宽度或者不做任何设置让其自适应内容

每一列div在高度上撑满父容器，超高内容会被隐藏。你可通过添加工具类scroll-y实现上下滚动。

上下滚动示例代码:

                <div class="opx-layout-hflex">
                    <div class="scroll-y">
                        左侧超高上下滚动
                    </div>
                    <div class="opx-flex-fill scroll-y">
                        右侧超高上下滚动
                    </div>
                </div>

左侧带导航菜单左右布局示例

示例代码:

                <div class="opx-layout-hflex">
                   <!--导航菜单作为最左列-->
                   <div class="opx-sidebar opx-collapsible w-lg">
                        <nav class="opx-sidebar-header opx-sidebar-header-fixed">
                            <span class="opx-sidebar-title">左右布局导航菜单示例</span>
                        </nav>
                        <div class="opx-sidebar-body">
                            <div class="list-group list-group-flush">
                                <a class="list-group-item list-group-item-light list-group-item-action" ng-repeat="link in layoutVm.links">
                                    <span class="opx-sidebar-collapsed-show text-center"><i class="fa fa-datasource-es"></i></span>
                                    <span class="opx-sidebar-expand-show">{{link.label}}</span>
                                </a>
                            </div>
                        </div>
                    </div>
                    <div class="opx-flex-fill scroll-y">
                        右侧超高上下滚动
                    </div>
                </div>

opx-sidebar是导航菜单的父容器,它的高度默认撑满父容器。它下面有两个直接子元素opx-sidebar-header和opx-sidebar-body。

菜单支持折叠和展开，你只需要给opx-sidebar添加类opx-collapsible,框架会自动帮你生成折叠按钮。菜单处于展开状态，隐藏包含opx-sidebar-expand-hidden类的元素；菜单处于折叠状态隐藏包含opx-sidebar-collapsed-hidden类的元素。

当opx-sidebar中内容高度大于100%时,它内部会出现纵向滚动条。可以通过给opx-sidebar-header添加opx-sidebar-header-fixed类来固定opx-sidebar-header使其不随其它内容一起滚动。

opx-sidebar-header通常会放置两种内容：标题或搜索框。这两个可以单独放置，也可以同时放置。上面的示例代码只有标题，只有搜索框的示例代码如下：

                <!--你需要自行监听搜索框内容变化来实现过滤效果-->
                <nav class="opx-sidebar-header border-bottom">
                    <input type="text" class="form-control w-full" placeholder="请输入搜索关键字">
                </nav>

两者同时存在的情况比较特殊，宽度不够用，显示效果也不好。所以框架会自动生成切换按钮来切换两者显示,默认展示标题。示例代码如下：

                 <nav class="opx-sidebar-header border-bottom">
                    <span class="opx-sidebar-title">左右布局示例</span>
                    <input type="text" class="form-control w-full opx-sidebar-search" placeholder="请输入搜索关键字">
                 </nav>
