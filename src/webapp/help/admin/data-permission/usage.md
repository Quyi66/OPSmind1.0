## 概览

数据权限目前只应用在数据工厂功能（数据服务 + 自定义页面）。

用户能看到的记录，必定是自己创建、有读或写权限或者是非受限的记录。换言之，没有读权限和写权限就看不到记录。

用户可以编辑的记录（能看到编辑、删除和保存按钮）,必定是自己创建或有写权限的记录。换言之，没有写权限就看不到编辑、删除和保存按钮。

即使通过特殊手段绕过页面流程，直接查看或编辑页面，也会被数据权限拦截。因为所有后台api都有数据权限校验。
