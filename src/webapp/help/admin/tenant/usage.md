## 概览

租户用户分为两类：普通用户和租户系统管理员。普通用户可以使用具体的功能模块，租户系统管理员除此之外还可以管理租户内其它用户。

## 操作界面

操作界面整体分为四块：

1. 登录界面
2. 用户管理
3. 数据服务
4. 自助页面

## 登录界面

![](../_media/images/tenant-step-login.png)

租户用户访问`http://host/oplus/<tenant-code>`-打开租户系统使用界面。每个租户有自己唯一的tenant-code和访问路径，租户创建完成之后不允许变更。假如tenant-code未注册，跳转错误页面“您访问的系统[non-exist-tenant]不存在”。

![](../_media/images/tenant-usage-step-nonetenant.png)

租户系统只允许属于当前租户的用户登录。无权用户可以联系租户管理员或超级管理员申请租户访问权限。

租户用户都是基础库用户的引用，所以同一用户在不同租户系统的账号密码等基本信息完全相同。同一用户在不同租户内的权限可以不同。


## 用户管理

![](../_media/images/tenant-usage-step-user.png)

租户系统的【用户管理】模块只对租户系统管理员可见。

假如要新增的用户在基础用户列表中不存在，请联系超级管理员维护用户基础库。

#### 租户用户配置

配置一个租户用户的基本步骤：

1. 在【用户管理】模块，点击【创建用户】。
2. 从用户列表中选择要添加的用户记录。
3. 根据实际需求设置此用户的角色。勾选`租户系统管理员该`之后此用户就可以管理租户内其它用户。
4. 点击【保存】后，将提示是否保存成功。
