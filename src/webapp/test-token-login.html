🔐 Token登录功能测试页面

测试说明：
  1. 本页面用于测试Angular应用接收Vue主应用传递的token功能
  2. Vue主应用已登录成功，传递的token是已认证的凭据
  3. Angular应用直接使用token作为认证凭据，获取用户信息和权限
  4. 不会重新发送登录请求，只获取用户账户信息
  5. 点击下方测试链接，观察浏览器控制台的日志输出
  6. 验证用户角色和权限是否正确加载，解决"无权访问"问题

⚙️ 功能特性

  • ✅ 自动检测URL中来自Vue主应用的token参数
  • ✅ 将token当作"登录成功确认"，触发标准登录流程
  • ✅ 自动获取完整的用户信息、角色和权限
  • ✅ 解决子页面"无权访问"问题
  • ✅ 处理完成后自动清除URL中的token
  • ✅ 兼容有token和无token的访问方式
  • ✅ 完整的调试日志输出
  • ✅ 错误处理和异常捕获
  • ✅ 防止重复处理同一token
  • ✅ 智能token缓存管理
开发提示：
  • 确保后端API支持 /api/authenticate/accessToken 接口
  • 检查租户配置是否正确设置
  • 验证JWT token的格式和有效性
  • 观察网络请求和响应状态
  • 确认后端返回完整的用户角色和权限信息
  • 检查权限配置是否正确，避免"无权访问"问题
