OpsMind是红帽专业服务部门的IT运维自动化解决方案，可以完成系统巡检、漏洞扫描、软件安装、使用者权限管理、信息采集等运维工作的自动化。

汇集了红帽一线工程师在IT运维方面的长期经验，通过标准化功能场景提供给用户。

同时提供强大的开发能力，用户可以通过低代码的开发方式进行功能定制，构建符合自身特性的自动化功能。

建立在业界领先的自动化运维工具Ansible之上，具备Ansible开放、简便、模块丰富、高度扩展等优势的同时，又在上面进行了大量功能扩展，让Ansible使用更简便和规范，自动化操作更加直观和易用。

采用无代理、模块化的设计，可适应不同规模的IT环境。在不替换现有运维架构的情况下，广泛兼容现有的运维系统和工具，最大程度保护现有的IT投资。
