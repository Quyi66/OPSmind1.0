## 🚀 使用方式

### 快速开始（推荐）
```bash
# 1. 验证环境
./validate-config.sh

# 2. 快速构建和运行
./quick-build.sh
```

### 完整构建
```bash
# 构建并运行
./build-oplus.sh --run

# 指定后端地址
./build-oplus.sh --backend 192.168.1.100:8080 --run

# 多架构构建并推送
./build-oplus.sh --push -r registry.example.com/
```

### 传统方式
```bash
# 使用现有脚本
./start-nginx.sh
```
